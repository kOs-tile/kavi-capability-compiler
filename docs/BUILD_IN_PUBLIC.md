# Build in public

Publish only claims backed by a shipped artifact, reproducible failure, benchmark, or dogfood result.

## Story
The project started after a real agent system accumulated tools, MCP surfaces, skills, APIs, filesystem access, and delegated execution. Individual permissions were understandable; the composed effective authority was not.

The key question became:

> What can this execution actually do, and why does it have those capabilities?

## Editorial rule
No invented launch metrics. No private infrastructure topology, credentials, customer data, internal authority keys, or sensitive Hermes state.
